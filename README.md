# form0-connector-pg

PostgreSQL connector for [form0](https://github.com/yourusername/form0) - enables automatic form submission storage in PostgreSQL databases.

## Overview

`form0-connector-pg` is a database connector that integrates with the form0 ecosystem to automatically store form submissions in PostgreSQL databases. It implements a hybrid storage approach, extracting common fields into dedicated columns for fast querying while preserving the complete form data as JSONB.

## Features

- **Hybrid Storage**: Common fields in dedicated columns + complete record as JSONB
- **Automatic Schema Creation**: Creates tables, indexes, and triggers automatically
- **Connection Pooling**: Efficient database connection management
- **Health Monitoring**: Built-in health checks and monitoring
- **Environment-based Configuration**: Secure credential management via environment variables
- **Debug Support**: Comprehensive logging for development and troubleshooting

## Installation

```bash
npm install form0-connector-pg
```

## Quick Start

### 1. Environment Setup

Create a `.env` file (copy from `env.example`):

```bash
# PostgreSQL Connection
FORM0_PG_HOST=localhost
FORM0_PG_PORT=5432
FORM0_PG_DATABASE=your_database
FORM0_PG_USERNAME=your_username
FORM0_PG_PASSWORD=your_password

# Optional Configuration
FORM0_PG_TABLE_NAME=form_submissions
FORM0_PG_SCHEMA=public
FORM0_PG_DEBUG=true
```

### 2. Basic Usage

```javascript
import { Form0PostgreSQLConnector } from 'form0-connector-pg';

const connector = new Form0PostgreSQLConnector();

// Initialize the connector
await connector.initialize();

// Submit a form record (as generated by form0-core record-transformer)
const result = await connector.onFormSubmit(structuredRecord);

if (result.success) {
  console.log('Record stored successfully:', result.id);
} else {
  console.error('Failed to store record:', result.error);
}

// Clean up
await connector.destroy();
```

### 3. With form0-cli (Coming Soon)

```bash

```

## Configuration

### Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `FORM0_PG_HOST` | No | `localhost` | PostgreSQL host |
| `FORM0_PG_PORT` | No | `5432` | PostgreSQL port |
| `FORM0_PG_DATABASE` | **Yes** | - | Database name |
| `FORM0_PG_USERNAME` | **Yes** | - | Database username |
| `FORM0_PG_PASSWORD` | **Yes** | - | Database password |
| `FORM0_PG_SSL` | No | `false` | Enable SSL connection |
| `FORM0_PG_SSL_REJECT_UNAUTHORIZED` | No | `true` | SSL certificate validation |
| `FORM0_PG_MAX_CONNECTIONS` | No | `10` | Connection pool size |
| `FORM0_PG_IDLE_TIMEOUT` | No | `30000` | Connection idle timeout (ms) |
| `FORM0_PG_CONNECTION_TIMEOUT` | No | `5000` | Connection timeout (ms) |
| `FORM0_PG_TABLE_NAME` | No | `form_submissions` | Table name for submissions |
| `FORM0_PG_SCHEMA` | No | `public` | Database schema |
| `FORM0_PG_DEBUG` | No | `false` | Enable debug logging |

## Database Schema

The connector creates a table with the following structure:

```sql
CREATE TABLE form_submissions (
  -- Primary identifier
  id UUID PRIMARY KEY,
  
  -- Common extracted fields (for fast querying)
  status VARCHAR(50),
  version INTEGER NOT NULL DEFAULT 1,
  draft BOOLEAN NOT NULL DEFAULT false,
  created_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ,
  created_at_client TIMESTAMPTZ,
  updated_at_client TIMESTAMPTZ,
  created_at_server TIMESTAMPTZ,
  updated_at_server TIMESTAMPTZ,
  created_by_id UUID,
  updated_by_id UUID,
  main_org_id UUID,
  sub_org_id UUID,
  project_id UUID,
  form_id VARCHAR(100),
  changeset_id UUID,
  
  -- Complete structured record as JSONB
  form_values JSONB NOT NULL,
  
  -- Database metadata
  created_at_db TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
  updated_at_db TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

### Indexes

The connector automatically creates indexes for optimal query performance:

- Common field indexes (status, form_id, dates, etc.)
- JSONB GIN indexes for flexible form_values queries
- Composite indexes for common query patterns

## API Reference

### Class: Form0PostgreSQLConnector

#### Methods

##### `initialize(config, envVars)`
Initialize the connector with configuration.

- `config` (Object): Optional configuration overrides
- `envVars` (Object): Optional environment variable overrides

##### `onFormSubmit(structuredRecord)`
Handle form submission from form0-core.

- `structuredRecord` (Object): Structured record from record-transformer.js
- Returns: `Promise<Object>` - Result with success/error information

##### `healthCheck()`
Check database connection health.

- Returns: `Promise<Object>` - Health status and connection info

##### `getMetadata()`
Get connector information and configuration.

- Returns: `Object` - Connector metadata

##### `destroy()`
Clean up resources and close connections.
